# 后端预约闭环、真实验证与流程演示

> 文档角色：已交付阶段的历史设计/实施记录（2026-11-12复核）。六项当时任务已完成（1c570fe）；独立讲解页docs/business-flow-demo.html随后在9d20e30删除，当前没有业务前端或该说明页。此处UI与费用/就诊人范围只指2026-10-26，不是当前能力边界。 当前能力与进度见[项目状态](../../docs/project-status.md)。

Status: resolved

## 目标

完善并验证注册登录、选择号源、创建预约、模拟支付、取消、超时关闭和预约凭证查询的后端闭环；另提供一份不接入业务接口的交互式页面，仅用于讲解业务流程。

## 验收

- 所有 API 响应中的 `Long` ID 输出为字符串，请求继续兼容字符串或数字 ID。
- 除注册登录外，业务 API 要求 Bearer Token，项目不提供业务前端入口。
- 业务流程说明页使用内置示例数据，可切换步骤、讲解视角和终态，不访问任何接口。
- H2 回归、MySQL 并发、实际监听端口 HTTP 测试通过。
- 说明页保持响应式、键盘可操作，并明确标识“纯流程演示”。

## 边界

不新增项目业务前端、管理后台、就诊人管理、真实支付、费用、退款或改签。预约生命周期仍遵循 ADR 0001。
