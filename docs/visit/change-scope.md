# 就诊功能交付变化

交付提交：`5d49ff9`，日期2026-11-11；后续三天窗口、消息和测试整理已完成。当前进度见[项目状态](../project-status.md)。

| 对象 | 交付前 | 交付后 |
| --- | --- | --- |
| 用户预约 | 查询预约、支付与快照 | 全部预约支持就诊时间排序、进度、当天签到 |
| 医生身份 | 医生档案与登录账号分离 | 管理员首次绑定已有账号并授予DOCTOR，重新登录 |
| 医生接诊 | 无专用接口 | 四场人数、人员名单、脱敏详情、开始与完成 |
| 数据模型 | 无就诊事实表 | V10新增visit_records，既有医生user_id可空唯一关联 |
| HTTP | 原预约列表和详情 | 新增7接口、扩展2个查询，见[API](api.md) |
| 资金与库存 | 预约确认后占用库存并获得号码 | 就诊动作保留这些事实，完成不释放库存 |

需求见[就诊需求](requirements.md)，实现入口见[设计](design.md)。当天签到只按上海日期；医生动作按归属、确认状态和进度，不额外限制日期。无前端、自动叫号、爽约、回退或病历处方。
