# 就诊功能交付变化

到院接诊首轮交付为`5d49ff9`（2026-11-11）；本页当前行为含2026-11-13签到窗口增量，基于`4bfc1d5`未提交工作区。当前进度见[项目状态](../project-status.md)。

| 对象 | 到院接诊引入前 | 当前行为（含窗口改造） |
| --- | --- | --- |
| 用户预约 | 查询预约、支付与快照 | 全部预约支持就诊时间排序、进度、窗口内签到 |
| 医生身份 | 医生档案与登录账号分离 | 管理员首次绑定已有账号并授予DOCTOR，重新登录 |
| 医生接诊 | 无专用接口 | 四场人数、人员名单、脱敏详情、开始与完成 |
| 数据模型 | 无就诊事实表 | V10新增visit_records，既有医生user_id可空唯一关联 |
| HTTP | 原预约列表和详情 | 新增7接口、扩展2个查询，见[API](api.md) |
| 资金与库存 | 预约确认后占用库存并获得号码 | 就诊动作保留这些事实，完成不释放库存 |

需求见[就诊需求](requirements.md)，实现入口见[设计](design.md)。签到按上海业务时间，使用预约日期和起止时间快照计算：开诊前30分钟开放（含），场次结束时截止（不含）。例如08:00–10:00允许在[07:30,10:00)首次签到，推荐07:30–08:00到院，08:00之后、10:00之前仍可签到。新旧尚未签到的已确认预约统一适用；已签到记录保留。超时未签到继续已确认且待签到，不自动取消、退款、释放库存、删除有效占用或标记爽约。医生动作按归属、确认状态和进度，不额外限制日期。无前端、自动叫号、爽约、回退或病历处方。

历史实施步骤、原文件清单与分阶段验收见[交付档案](../../.scratch/archive/visit-workflow/summary.md)。当前最新实际验收见[验证报告](../verification-report.md)，各自检查点的结果分别保留。

## 签到窗口增量

- 全天签到改为[预约开始前30分钟,预约结束)，按预约快照而非当前场次枚举计算。
- 用户列表/详情visit追加checkInOpensAt和checkInClosesAt；已签到/完成仍返回窗口，其他预约visit=null。
- 过早4503、截止4504，均HTTP409；状态和重复冲突4502优先。现有REST、医生DTO、数据库V10及24小时取消规则保持。
- 新旧未签预约统一按新窗口，已签到事实不撤销，医生可在截止后或跨日接诊。参见[ADR0008](../adr/0008-visit-checkin-window.md)和[场景覆盖](../testing/scenario-coverage.md#签到窗口)。
