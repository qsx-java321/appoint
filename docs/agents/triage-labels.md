# Triage 标签

工程技能使用以下五种 canonical triage role，本项目直接使用对应的英文标签字符串：

| 工程技能角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待需求提出者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求清晰，可交给 agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 暂不处理 |

当技能提到某个 triage role 时，使用表格中对应的标签。
