# 就诊人信息填写示例

本文提供可在项目页面中直接填写的就诊人示例，供本地体验注册、就诊人管理和预约流程时使用。姓名、联系方式按演示用途编写，身份证号码为符合项目校验规则的样例，不代表经过核验的真实身份。

## 如何使用

1. 注册并登录普通用户账号。demo 环境的入口为 [注册页面](http://127.0.0.1:5173/register)，已有账号可直接登录。
2. 进入“就诊人”页面，点击“新增就诊人”。demo 环境可直接打开 [就诊人页面](http://127.0.0.1:5173/patients)。
3. 从下表选择一行，逐项复制到表单。证件类型已固定为“居民身份证”，无需手动填写。
4. 点击“保存就诊人”。列表中出现对应姓名且状态为“已启用”，即可在预约时选择这位就诊人。

账号用于登录，就诊人代表实际看病的人；一个账号可以添加下表中的多位就诊人。联系邮箱可以与注册邮箱相同，也可以直接使用各示例中的邮箱。

## 第一次填写时怎么理解各项

以“张小明”为例：

| 页面字段 | 填写内容 | 说明 |
| --- | --- | --- |
| 姓名 | 张小明 | 填就诊人的姓名；可以与登录账号的使用者不同 |
| 证件类型 | 居民身份证 | 页面已固定，保持原样 |
| 身份证号码 | `11010519491231002X` | 复制完整的 18 位号码，最后一位是英文字母 `X` |
| 联系电话 | `13800138000` | 填用于联系这位就诊人的电话 |
| 联系邮箱 | `zhangxiaoming@example.com` | 填完整邮箱，也可换成自己的注册邮箱 |

保存后，身份证号码会显示为 `110105********002X`，这是正常的脱敏展示。再次新增就诊人时，仍需填写完整号码，不能复制带星号的号码。

## 填写失败时怎么处理

| 提示或现象 | 处理方式 |
| --- | --- |
| 提示“请求参数不合法” | 检查必填项是否为空、邮箱格式是否完整，以及身份证号码是否与示例完全一致；具体字段约束见 [就诊人 API](api.md#就诊人管理) |
| 身份证号码长度不够或无法保存 | 复制完整的 18 位号码；不要随意修改其中的出生日期或末位校验字符 |
| 提示“该证件已登记为就诊人” | 当前账号已经添加过该号码，请使用已有记录，或换用表中另一位就诊人 |
| 已有记录显示“已停用” | 点击“启用”后再用于预约，无需重复新增 |
| 提示“请先登录或重新登录” | 重新登录当前环境后再操作 |
| demo 重启后找不到账号或就诊人 | demo 每次后端启动都会恢复初始数据；重新注册并按本文添加即可，详见 [环境说明](environments.md) |

字段约束、重复证件处理等规则以 [就诊人 API](api.md#就诊人管理) 为准；后续预约操作见 [注册到预约成功](business-flow.md#注册到预约成功)。
