# ADR 0007：三天预约窗口与场次截止

状态：已接受，2026-11-11。替代 [ADR 0005](0005-four-session-on-demand-booking.md) 中 D+1～D+7、禁止当天创建和只按创建时间计算支付截止的决定；其四场、按需生成、统一设置及快照决定保留。

为支持当天就诊并将预约入口集中为今天、明天、后天，新订单按上海业务时间采用 D～D+2 窗口。保留四个固定场次，每场在开始前十五分钟停止创建新订单；所有截止采用严格早于比较。选择提前停止接单，为已有十五分钟支付窗口留出时间；不采用临开诊仍接单、再压缩最后几单支付时间的方案。

共享纯规则位于 `catalog.model.BookingTimeRules`，目录与创建使用同一计算。创建在设置、场次和就诊人锁定后、实际条件占号前采样预约准入时间，并用该时刻生成预约及支付的创建时间和截止快照。支付截止为准入时间加配置支付时限（当前十五分钟）与场次开始时间的较早者。

停止新下单不禁止原订单在自己的期限内支付；跨零点后原明天变今天仍可具备创建资格，订单也可跨零点付款。查询入口滚动不删除旧预约、不重算旧支付截止。三天目录保留十二项，派生可预约状态，不增加持久化状态、数据库迁移或 REST 路径。[ADR 0006](0006-late-payment-and-consumer-retries.md) 的既有收款时间及预约确认语义继续沿用。
