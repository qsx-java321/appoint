# ADR 0006：迟到支付关闭预约及支付成功事件有界重试

> 本文保留迟到支付与消费者重试的历史设计。现行支付流程见 [ADR 0009](0009-synchronous-simulated-payment.md)。

**状态** 已接受 · **记录日期** 2026-11-08

> 收款时间与迟到退款见[业务流程](../business-flow.md#支付截止与异步确认)。消费者重试与恢复见[模块设计](../module-design.md#事件重复与恢复)。

待支付预约收到确认时间不早于支付截止时间的成功事件时，协调事务将预约置为 EXPIRED、释放暂占、删除有效占用并确保退款；Inbox 与这些事实原子提交。截止前已确认收款的事件即使延迟到达仍可确认预约。旧数据先只读盘点，不自动修复。

支付成功事件首次处理及两次重试合计三次，重试间隔一秒；无效消息直接进入 DLQ，重试耗尽进入 DLQ。重试和受控重放转发在确认 Broker 接收且无 mandatory return 后才确认原消息，重复投递仍由 Inbox 和条件更新保护。
